# Surface brief: Withheld, home and program lookup (index.html)

**Mode:** Operate (the visitor completes a task: look up a program, read the verdict), with a persuasive first viewport because GIBC judges arrive cold.
**Audience / job:** a high-school senior and a parent checking a program before borrowing; a judge deciding in under a minute whether this is real. **Proof:** the real federal file (233,979 rows), the real share withheld (77.7 %), held-out validation numbers generated by `pipeline/`.
**Memorable moment:** the blue-pencil pass. Blank rows of the federal printout fill in with estimates and their brackets, and the red rule of the earnings line splits them.
**Unresolved:** the per-state threshold source (see PRODUCT.md).

## Direction contract
THESIS: The student-loan record rendered as the batch printout it was born as: a green-bar report where the machine prints only what it's allowed to, and an analyst's non-photo-blue pencil annotates estimates in the margins. It refuses the fintech default of cards, gauges, gradient charts and a hero illustration.
OWN-WORLD: White continuous-feed paper with pale green 3-line bands, sprocket-hole margins, perforated tear rules between sections, and report headers (RUN DATE, PAGE, SOURCE, SHA-256). Official figures are set in line-printer ink (blue-black mono). Estimates are always in non-photo-blue pencil, prefixed ≈ and bracketed [low–high]. One red ruled line: the federal earnings line. Public Sans for prose; Doto dot-matrix numerals for the few giant figures.
STORY: The visitor sees how much of the federal record is blank, learns that Withheld estimates rather than reveals, looks up a program, and leaves knowing which side of the line it likely sits on and how sure that is.
FIRST VIEWPORT: Full-bleed green-bar sheet. The header strip carries the report line and the PROGRAM LOOKUP field (the primary action). Left five columns: a dot-matrix "181,758" plus one sentence. Right seven: the live field, 233,979 ticks on the bands (y = earnings, log scale). Published ticks are inked; withheld ticks start blank and get pencilled in; the red rule crosses it.
FORM: green-bar continuous-feed batch printout. Candidate 6 of 7 (seed 262974cf, re-roll 1; candidate 5, the redacted-document world, was declined on product truth because it frames lawful privacy suppression as a cover-up and implies un-redaction, which Withheld refuses).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
