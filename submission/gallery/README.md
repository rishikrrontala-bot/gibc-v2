# Gallery

All seven images are **1500 × 1000 PNGs**, captured from the running application. Captions are included in the images and supplied separately to Devpost.

1. `01-the-gap.png` — the missing-data problem and search entry point.
2. `02-the-model-view.png` — reveal official observations, supported estimates and unsupported records.
3. `03-program-evidence.png` — a labelled estimate and its uncertainty interval.
4. `04-comparison.png` — compare an estimate and a published outcome without losing provenance.
5. `05-validation.png` — test error, baseline comparisons and interval undercoverage.
6. `06-limitations.png` — why held-out published-data validation cannot establish hidden-outcome accuracy.
7. `thumbnail.png` — the project cover image.

The six gallery images and thumbnail have been uploaded to the saved Withheld Devpost draft. Reproduce them with `node scripts/capture.mjs` after installing Playwright's Chromium. In an environment using an existing browser binary, set `CHROMIUM_PATH`.
