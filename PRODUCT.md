# Withheld — shipped product

The source of truth for this build is README.md, the generated data manifest and the running application. Earlier research/CONCEPTS.md records the original plan, not shipped claims.

An uncertainty-first college-program earnings research explorer for students, families and evaluators. Uses the official June 10, 2026 College Scorecard release. Search all campus program records; inspect published values or supported model estimates; compare programs; export clearly labelled results; experiment with a hypothetical fixed-rate loan; review honest held-out validation.

The product is a research prototype, not financial advice. It does not predict an individual's salary, determine federal eligibility, recover suppressed records or operate on real money. It prominently separates published, estimated and unsupported outcomes. Inference happens offline in a reproducible Python pipeline; browser outputs are the frozen results, not a hosted API or live model claim.

Primary flow: find college → filter/select program → read source and interval → optionally adjust a hypothetical benchmark and loan → compare → inspect the method. No accounts or user-data collection. Session-local comparison pins. Public program deep links. Data loads by state.

The user explicitly requested Unseen Studio–inspired design, replacing the earlier green-bar-paper design intent. The implementation uses spacious mixed typography, soft blush/plum surfaces and a purposeful sample-to-distribution visualization; no borrowed brand assets.
